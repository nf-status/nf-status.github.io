Дані

Експорт зберігає всі дані (рецепти, склад, журнали, звіти) у JSON-файл – це ваша резервна копія. Файл не зашифрований, тож тримайте його в надійному місці. Імпорт повністю замінює поточні дані даними з файлу.

Синхронізація між пристроями
Синхронізацію не підключено – дані зберігаються лише в цьому браузері.
Сховище ще порожнє. Натисніть «Імпорт з файлу» вище й оберіть останній експорт (.json) – після цього дані з’являться на всіх ваших пристроях.
Як налаштувати (один раз)
  1. Натисніть «Згенерувати» біля поля «Ключ».
  2. Відкрийте script.google.com → «Новий проєкт».
  3. Натисніть «Скопіювати код» нижче, вставте його в редактор замість усього вмісту й збережіть.
  4. Розгорнути → Нове розгортання → тип Веб-застосунок. Виконувати від імені: Я. Доступ: Усі. Дозвольте доступ до Google Диска.
  5. Скопіюйте URL веб-застосунку, вставте в поле вище й натисніть «Підключити».
  6. На телефоні відкрийте посилання з кнопки «Скопіювати посилання для іншого пристрою».

function doPost(e) {
  try {
    var payload = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName(payload.sheet);
    if (!sheet) {
      sheet = ss.insertSheet(payload.sheet);
      sheet.appendRow(payload.headers);
      sheet.getRange(1, 1, 1, payload.headers.length)
           .setFontWeight('bold').setBackground('#E8EAF6');
    }
    sheet.appendRow(payload.row);
    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
